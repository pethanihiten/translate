⚙️ Offline setup

One click fetches the on-device models. The chrome://flags toggles must be enabled once by hand — the browser won't let a page do that (steps below).
📥 How to add the offline models (one-time setup)
This tool uses Chrome's on-device AI so everything runs offline. You need Chrome 138+ (or recent Edge). Do this once:
  1. In the address bar open chrome://flags. Search each flag below and set it to Enabled:
    • Prompt API for Gemini Nano → the Simple / Medium / Advanced rewrites.
      chrome://flags/#prompt-api-for-gemini-nano
    • Translator API → English → Hindi, fully offline.
      chrome://flags/#translation-api
    • Proofreader API for Small Expert Model → offline grammar fix.
      chrome://flags/#proofreader-api
  2. Click Relaunch (bottom of the flags page) to restart Chrome.
  3. Come back here and press the ⬇️ Download offline models button just above these steps. First run downloads the small models (a few minutes) — watch progress in the status bar.
  4. When the status bar shows “run fully offline on-device ✅”, you're done. It stays offline after that.
Tip: you can also watch model downloads at chrome://components → “Optimization Guide On Device Model”. Until setup is finished, the tool still works — English cleanup runs offline and Hindi falls back to a free online translator.
